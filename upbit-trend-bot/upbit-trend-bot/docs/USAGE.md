# 업비트 자동매매 봇 (BTC·ETH)

봇은 **AWS 서버(시드니, YOUR_SERVER_IP)** 에서 돌아요. 이 PC 폴더는 설정을 바꾸고 서버에 올리는 용도예요.

## 매일 쓰는 것: 텔레그램
| 명령 | 하는 일 |
|---|---|
| `/status` | 지금 상태 (작동 여부, 자산, 코인별 판단) |
| `/dashboard` | 대시보드 파일 (휴대폰에서 열기) |
| `/stop` | 즉시 정지 (보유 코인은 그대로) |
| `/resume` | 다시 시작 |
| `/log` | 최근 실행 기록 |
| `/export` | 매매일지 파일 (세금 신고·복기용으로 가끔 받아 두기) |

자동으로 오는 알림: 매수·매도·손절, 자동 정지, 멈춤 감지, 매일 오전 9시 요약과 대시보드.

## 전략: 추세+모멘텀 + 변동성 비중조절
- **살 때:** 가격이 200일선 위이고, 단기 흐름(EMA12)이 중기 흐름(EMA26)보다 위일 때
- **얼마나:** 목표 변동성 60% ÷ 최근 20일 변동성 (최대 100%). 거칠면 적게, 잔잔하면 많이
- **팔 때:** 두 조건 중 하나라도 깨지면 전량 매도. 평균 매수가 대비 -5%면 손절
- **언제:** 매일 오전 9시 7분에 판단, 손절은 매시 7분에 확인
- **검증:** 2020~2026 BTC·ETH 반반 기준 연 60%, 최대 낙폭 -24%. 과거 성과는 미래를 보장하지 않아요.

## 설정을 바꾸고 싶을 때 (예: 투자 한도 늘리기)
1. 업비트에 원화를 더 입금
2. 이 폴더의 `config.py` 를 메모장으로 열어 `LIVE_MAX_KRW = 50_000` 의 숫자를 바꾸고 저장
3. `upload_to_server.bat` 실행 → 이 폴더의 파일로 서버를 업데이트 (봇 상태와 기록은 그대로)

| 설정 | 지금 값 | 의미 |
|---|---|---|
| `LIVE_MAX_KRW` | 50,000 | 봇이 쓸 수 있는 최대 원화 |
| `VOL_TARGET` | 0.6 | 목표 변동성 (낮추면 더 보수적) |
| `STOP_LOSS` | 0.05 | 손절선 |
| `REBALANCE_BAND` | 0.10 | 비중 조정 최소 차이 |
| `ENTRY_MIN_ADX`, `TRAILING_STOP` | None | 대시보드 '점검' 탭이 제안할 때만 검토 |

## 안전장치
- `LIVE_MAX_KRW` 까지만 사용, 봇이 산 수량만 매도 (원래 갖고 있던 코인은 안 건드림)
- 주문 오류·잔고 불일치·하루 주문 6회 초과 시 스스로 멈추고 알림 → 원인 확인 후 `/resume`
- 일시적인 네트워크 오류는 다음 실행 때 자동 재시도 (알림은 6시간에 한 번만)
- API 키 만료 30일 전부터 매일 요약에 경고

## 이 폴더의 파일
| 파일 | 용도 |
|---|---|
| `.env` | 업비트·텔레그램 키 (**절대 공유 금지**) |
| `LightsailDefaultKey-*.pem` | 서버 접속 열쇠 (**절대 공유 금지**) |
| `upload_to_server.bat` | 설정·코드를 서버에 반영 |
| `live_check.bat` | 이 PC에서 업비트 연결 점검 (주문 없음) |
| `config.py` | 설정 |
| 나머지 `.py` | 봇 코드 (서버로 올라감) |
| `_보관` 폴더 | 예전 PC 실행용 파일과 연구용 백테스트 (지금은 안 씀) |
